# Опросник «Посчитать проект» — Costa Frame

Создайте форму: [Google Forms](https://forms.google.com/create)

**Название:** Costa Frame — расчёт проекта  
**Описание:** Короткий опрос по съёмке в Коста-Бланке. Ответы придут на почту — после этого пришлём базовый расчёт.

Настройки: ответы → указать email; включить «получать уведомления о новых ответах».

После публикации скопируйте ссылку «Отправить» и вставьте в `src/config.js` → `quoteFormUrl`.

---

## Вопросы

### 1. Имя *
Тип: короткий текст

### 2. Контакт для связи *
Тип: короткий текст  
Подсказка: телефон, WhatsApp или email

### 3. Тип съёмки *
Тип: один вариант
- Камера
- Дрон
- Камера + дрон
- Пока не уверен(а)

### 4. Нужен монтаж? *
Тип: один вариант
- Да, с монтажом
- Нет, только материал
- Частично / обсудим

### 5. Формат проекта *
Тип: несколько вариантов
- Контент для соцсетей / рилсы
- YouTube / длинное видео
- Событие / торжество
- Подкаст / интервью
- Beauty / бренд
- Семейная съёмка
- Другое

### 6. Ориентировочная длительность съёмки *
Тип: один вариант
- 2 часа (минимум)
- 3–4 часа
- Полный день (6–8 часов)
- Несколько дней
- Пока сложно сказать

### 7. Локация
Тип: короткий текст  
Подсказка: город / район Коста-Бланки или «выезд уточним»

### 8. Желаемые даты
Тип: короткий текст  
Подсказка: конкретные дни или «гибко»

### 9. Кратко о задаче
Тип: длинный текст  
Подсказка: что снимаем, сколько роликов, есть ли референсы

### 10. Бюджет (ориентир)
Тип: один вариант
- До 300 €
- 300–600 €
- 600–1000 €
- 1000+ €
- Пока без рамки — нужен расчёт
